📌 Overview

The Quarterly Dispute Tracker is an interactive Excel dashboard designed to monitor and analyze dispute cases across multiple quarters. It provides key performance indicators (KPIs), trend analysis, and visual reports to help identify pending cases, resolved cases, and overall dispute performance.

🚀 Features
Interactive dashboard with slicers and filters
Quarterly dispute analysis
KPI cards for key metrics
Trend charts for dispute performance
Pending vs. Resolved case tracking
Easy-to-use Excel interface
📊 Dashboard Insights
Total Dispute Cases
Resolved Cases
Pending Cases
Resolution Rate
Quarterly Trends
Category-wise Analysis
Performance Summary
🛠️ Tools Used
Microsoft Excel
Pivot Tables
Pivot Charts
Slicers
Conditional Formatting
Excel Formulas
